## About me

I'm a Senior Fullstack Engineer with 6+ years building production web applications in TypeScript: Node.js and NestJS on the server, React, Next.js and Angular on the client. I own features end to end, including the REST and GraphQL APIs behind them and the cloud-native services that run them on AWS with Docker and Kubernetes.

Since 2022 I have been embedded full-time in a US healthcare SaaS through [Improving](https://improving.com), shipping HIPAA-compliant features across a TypeScript microservices platform. I integrate AI into real product workflows, such as vector embeddings for semantic search, and I use AI pair-programming tools to move faster without compromising code quality.

- 📍 Guadalajara, Jalisco, Mexico (CST, UTC-6)
- 🎓 M.Sc. in Information Technology, Universidad de Guadalajara
- 🧩 Previously contributed to IBM's Carbon Design System as a UX/UI designer
- 🎤 Community regular at AWS User Group Jalisco, KCD Guadalajara and PosaDev, and speaker at universities and Talent Land
- 🌱 Currently learning: agent design, prompt and context engineering, MCP and tool integration
